v0.6.6
------

API changes
###########

* Moved to clearly continuous time for pathway planning (formerly multi-period)
  optimisation. Instead of defining periods, users now can give
  `investment times` at which capacities (may) change. Consequently, many
  parameters that were scalars before can now be iterable. In contrast to the
  former multi-period implementation, it is possible to give a time series of
  fixed capacities without any investment.
* Avoid creation of empty variables (i.e. variable vectors of zero length).
* Remove `solver-results` attribute from Model class. It will be replaced by
  the new `solver_return` attribute.

New features
############

* Added a solver attribute to the Results class to get the return values of
  the solver in a structured way
* Added dual-variables and reduced cost to the Results class
