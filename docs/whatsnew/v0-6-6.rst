v0.6.6
------

API changes
###########

* Moved to clearly continuous time for pathway planning (formerly multi-period)
  optimisation. Instead of defining periods, users now can give
  `investment times` at which capacities (may) change. Consequently, many
  parameters that were scalars before can now be iterable. In contrast to the
  former multi-period implementation, it is possible to give a time series of
  fixed capacities without any investment.
* Avoid creation of empty variables (i.e. variable vectors of zero length).
* ExtractionTurbineCHP is deprecated and will be replaced by
  VariableSplitConverter. The new class is more flexible but will cover all
  use cases of the ExtractionTurbineCHP

New features
############

* VariableSplitConverter: A converter with one input and two competing
  outputs, where the split between the outputs can vary linearly between two
  given, real operating points (e.g. an extraction/backpressure turbine, where
  the split between electricity and heat varies with the amount of heat
  extracted).
